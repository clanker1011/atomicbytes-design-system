# Mid-century shapes

boomerangs, starbursts, orbits, blobs, panels. **Not** traced from stock clip art.

Colors: ink `#1C1915`, coral `#FF5B3C`, mint `#2EE6A6`, cobalt `#4B6BFF`, yolk `#FFD84A`, paper `#F6F1E8`.
