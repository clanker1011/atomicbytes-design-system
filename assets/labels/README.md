# Labels

Small AtomicBytes marks for claiming human authorship.

| File | Use |
|------|-----|
| `human-made-stamp.svg` | Circular rubber stamp for article headers / footers |
| `handset-stamp.svg` | Wide stamp for hero trays / Issue 00 chrome |
| `human-made-badge.svg` | Tiny byline pill |

Type on sticker fills should stay print-ink (`#1C1915`). Keep on cream paper or a surface that preserves contrast.
