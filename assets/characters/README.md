# Character assets

Mid-century atomic optimism: 1950s poster-style mascots with cream grounds, bold ink outlines, and coral / mint / cobalt accents.

Every cast member ships an **SVG source** plus a PNG raster. Prefer SVG for crisp scaling; PNG is fine for quick drops and places that still want a bitmap.

| SVG source | PNG | Role |
|------|------|------|
| `atomicbyte.svg` | `atomicbyte.png` | Primary Bohr-atom logo face (smirk nucleus + orbiting electrons) |
| `atomicbyte-mark.svg` / `atomicbyte-face.svg` | — | Hand-authored logo mark (from `mascots/A.svg`) — prefer for wordmarks & favicons |
| `atom-salesman.svg` | `atom-salesman.png` | Pitchman mascot — suited atom with bow tie, pointing pose |
| `byte-bot.svg` | `byte-bot.png` | Retro robot companion with atom chest screen |
| `byte-rocket.svg` | `byte-rocket.png` | Energetic rocket mascot (speed / launch moments) |
| `atomic-mark.svg` | `atomic-mark.png` | Abstract atom mark for badges and simplified brand use |

**Notes**
- Full-body SVGs (`atomicbyte.svg`, `atom-salesman.svg`, `byte-bot.svg`, `byte-rocket.svg`, `atomic-mark.svg`) were vectorized from the cleaned production PNGs (no pick-sheet letter labels).
- `atomicbyte-mark.svg` is the hand-drawn Bohr mark — use that for logo lockups when you need the cleanest paths.
- **Rejected:** Lab Tech (old cell D) is not shipped here.
