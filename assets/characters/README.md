# Character assets

Mid-century atomic optimism: 1950s poster-style mascots with cream grounds, bold ink outlines, and coral / mint / cobalt accents.

**The logo is AtomicByte** — `atomicbyte.svg` / `atomicbyte.png`. Same files as the Characters section. Do not maintain a separate “mark” asset for brand identity.

Every cast member ships an **SVG source** plus a PNG raster. Prefer SVG for crisp scaling.

| SVG source | PNG | Role |
|------|------|------|
| `atomicbyte.svg` | `atomicbyte.png` | **Logo** — primary Bohr-atom face (smirk nucleus + orbiting electrons) |
| `atom-salesman.svg` | `atom-salesman.png` | Pitchman mascot — suited atom with bow tie, pointing pose |
| `byte-bot.svg` | `byte-bot.png` | Retro robot companion with atom chest screen |
| `byte-rocket.svg` | `byte-rocket.png` | Energetic rocket mascot (speed / launch moments) |
| `atomic-mark.svg` | `atomic-mark.png` | Geometric trademark atom (no face) for seals / small monograms |

**Notes**
- Full-body / character SVGs were vectorized from the cleaned production PNGs (no pick-sheet letter labels).
- `atomicbyte-mark.svg` / `atomicbyte-face.svg` are older hand-authored Bohr sketches kept for reference only — **do not use as the logo**. Use `atomicbyte.svg`.
- **Rejected:** Lab Tech (old cell D) is not shipped here.
