02

Principles

Whimsical, still craft-serious. A toy workshop that ships — not a circus, not dark SaaS.

  • mood

    Atomic optimism

    Mid-century poster energy. Confident smirk, not corporate grin. Hope with ink under the fingernails.

  • surface

    Ink on paper

    Warm cream field, warm near-black type. Everything sits on paper — never a black void with neon fog.

  • accents

    Stickers, not glows

    Coral, mint, cobalt, yolk fill shapes that keep an ink outline. No blurry drops, no glass, no rainbow haze.

  • tone

    Craft, not circus

    Fun is allowed. Clowning is not. One accent per component; two at most. Serious studio with a wink.

  • layout

    Fits the pocket

    Small screen is the default canvas. If it sings at 320, 1280 is a victory lap. See Responsiveness.

03

Responsiveness

This page is the spec and the product. If it pinches, spills sideways, or hides a tap, the system is fibbing. Pocket first. Desk later.

  • why

    The pocket is the page

    Most visits aren’t at 1280. A layout that only works on a cinema display is a poster, not a product. If it isn’t usable at 320, it isn’t shipped.

  • default

    Mobile-first, not collapsed-desktop

    Write the small-screen CSS as the default. Min-width queries add columns, side-nav, and air. Don’t design a desk and then smash it with max-width.

  • type

    Fluid type & space

    Clamp headings so they hit the scale on a desk and stay readable in the hand. Comfortable measure — no 90-character lines on a phone, no 12px body.

  • touch

    Forty-four pixels, no excuses

    Theme, nav chips, buttons, and fields get ~44px targets. Fingers are not cursors. If you have to pinch to tap the Day–Night atom toggle, you failed the brief.

Do Pocket rules

  • Mobile-first CSS: small is the default, min-width enhances
  • Fluid type with clamp that still hits the desktop scale
  • ~44px tap targets on theme, chips, buttons, fields
  • No document-level horizontal scroll — code and tables scroll inside themselves
  • Images and SVG: max-width: 100%, height: auto
  • Test at ~320, 375, 768, 1024, then 1280+

Don’t Desk habits

  • A 900px layout that “collapses” and calls it responsive
  • overflow-x: hidden on body to hide a broken grid
  • Tiny nav chips or a theme toggle that scrolls off-screen
  • Sticky chrome that eats half the viewport
  • Fixed widths, unbreakable strings, or lockups that refuse to wrap

Test widths

These aren’t devices. They’re checkpoints. If it sings at 320, 375 is easy. If it only works at 1024, start over.

  • 320 Floor Narrowest we promise. One column. No sideways scroll.
  • 375 Hand Common phone. Type measure, tap targets, stacked hero.
  • 768 Lap Two-up grids. Still the top-nav, not the sidebar.
  • 1024+ Desk Sticky side-nav, wider measure, lockups in a row.

04

Color

All UI sits on warm paper (or night paper). Accents behave like inks, stickers, and stamps. Swatch hexes follow the active theme — see Theming.

  • Paper #F6F1E8 --paper
  • Paper shade #EBE4D6 --paper-shade
  • Ink #1C1915 --ink
  • Muted #5A544A --muted
  • Coral #FF5B3C --coral / --accent
  • Mint #2EE6A6 --mint / --accent-3
  • Cobalt #4B6BFF --cobalt / --focus
  • Yolk #FFD84A --yolk / --accent-4
  • Surface #FFFBF3 --surface
  • Surface inset #E8E0D0 --surface-inset

Do Ink rules

  • Body text is always ink on paper or surface
  • Accent fills carry ink type and an ink stroke
  • Links: ink type, cobalt underline
  • Focus: 3px cobalt ring, 3px offset
  • One accent per component (two max)

Don’t Old habits

  • Mint or yolk as body text
  • White-on-coral (fails contrast)
  • Neon glows, glass, dark SaaS voids
  • Revive #0b0c10 / cyan / violet / pink
  • Cobalt as 16px link text color

05

Theming

One token sheet, two papers. Light is cream (the default). Dark is mid-century night paper — warm ink field, soft cream type, same sticker accents. Not neon SaaS.

  • data-theme="light"

    Cream paper

    Field #F6F1E8 · type #1C1915. Default, and the look of print.
  • data-theme="dark"

    Night paper

    Field #241F18 · type #F3EDE2. A darkroom desk, not a void.

How tokens map

Color custom properties swap under [data-theme="dark"]. Type, space, radius, and stroke weights stay put. Components should consume vars — never a raw hex — so they follow the theme.

Token Light Dark Role
--paper #F6F1E8 #241F18 Page field
--paper-shade #EBE4D6 #1C1813 Playgrounds, table heads
--ink #1C1915 #F3EDE2 Type + outlines + stamp shadows
--muted #5A544A #C4BAAE Secondary type
--line #1C1915 #E8DFD0 Softer stroke when you need it
--surface #FFFBF3 #2F2921 Raised cards / chrome
--surface-inset #E8E0D0 #1A1611 Wells, inset fills
--code-bg / --code-fg #1C1915 / #F6F1E8 #16130F / #F3EDE2 Code slabs — deeper than the field
Accents coral · mint · cobalt · yolk coral · mint · cobalt #8AA0FF · yolk Stickers. Cobalt lightens in dark so type hits AA.
--on-accent #1C1915 — always print-ink Type sitting on coral / mint / yolk / cobalt fills

Dark rules

Do Night paper

  • Ink outlines become cream / light strokes — --ink inverts, so borders and --shadow-stamp follow
  • Type on sticker fills uses --on-accent (print-ink #1C1915) — cream on coral is 2.65:1 and fails
  • Cobalt lightens to #8AA0FF so kickers, focus, and code keywords hit 4.5:1
  • Use --line (#E8DFD0) when a full cream stroke is too loud
  • Code slabs stay warm ink plates, just deeper than the page (--code-bg #16130F)
  • Sit raster mascots on --mascot-field (always cream #F6F1E8)
  • Honor an explicit toggle over prefers-color-scheme

Don’t Old dark

  • Revive #0b0c10, cyan, violet, or pink
  • Glassmorphism, blur, or neon glows
  • Recolor PNG characters — rasters are print-ink on cream
  • Mint or yolk as body text (still)
  • Cream type on coral, mint, or yolk fills
  • Cool charcoal fields; night paper is warm

Paper patterns

Three paper surfaces for later. Specimens below are boosted so you can tell them apart — production fills stay quieter. Workshop grid is what the DS uses today. Don’t stack all three on one page. Cards and code slabs stay solid either way.

  • A · current Workshop grid

    Faint desk grid + film grain. What the DS uses today.

    Workshop grid

    Hairline grid on paper, grain overlay on top. Safe default for the whole site.

  • B · candidate Dot paper

    Soft risograph dots. More fiber, still readable.

    Dot paper

    A barely-there dot screen — print-shop paper without the noise. Good if the grid feels too “engineer desk.”

  • C · candidate Sparse sparks

    A few tiny sparks in the field. Band accent, not full-page wallpaper.

    Sparse sparks

    Use as a section treatment (hero or footer), not the global page fill. Keep density low or it turns into clip art.

Do Pattern rules

  • Keep contrast: body type must still clear WCAG on the patterned field
  • Solid surfaces for cards, code, and forms
  • One global pattern; sparks only as a local band
  • Tone down further in night paper (opacity follows the theme)

Don’t Wallpaper

  • Full-bleed shape mosaics behind long reading
  • Animated patterns or parallax glitter
  • Pattern on top of code slabs or inputs
  • Mixing grid + dots + sparks on the same page

Toggle + persist

The Day–Night atom icon toggle in the sidebar (and mobile header) sets data-theme on <html> and writes localStorage.ab-theme. If nothing is stored, the page follows prefers-color-scheme. Flip it — cards, buttons, quotes, forms, and code slabs should all track.

/* tokens.css — color is the only layer that swaps */
:root { /* cream paper defaults */
  --paper: #F6F1E8;
  --ink: #1C1915;
}
:root[data-theme="dark"] { /* night paper */
  --paper: #241F18;
  --ink: #F3EDE2;
}

Clearspace

Minimum padding around AtomicByte equals half the character’s width (½ W). No type, stamps, or stickers inside that field.

½ W ½ W

On an 80px AtomicByte, that’s 40px of cream on every side. Scale the padding with the character — don’t freeze it at a pixel value.

Minimum sizes · digital

14

Motion

Slow orbits, tiny stamp lifts. Nothing pulses. If the user asked for less motion, give them stillness.

Do Spec

  • Orbits ~18–24s linear (--orbit-fast / --orbit-mid / --orbit-slow)
  • Button / card stamp hover: lift 1–2px, shadow lengthens 3→4
  • CSS only — no JS animation libraries
  • Honor prefers-reduced-motion: kill orbits, kill tilt, no jump-scroll

Don’t Old habits

  • Neon pulses, glow breathe, rainbow shimmer
  • Bounce easings or 200ms “delight” pops
  • Parallax that fights the paper
  • Animating when reduced-motion is on

Orbit · 18 / 22 / 24s linear. Stops under reduced-motion.

Adoption

How to use tokens.css in a future site. This design-system folder is the source of truth before the marketing rebuild.

  1. Copy the tokens

    Bring design-system/tokens.css (or the :root block) into the real site as the single color/type/space source.

  2. Load the three families

    Sixtyfour Convergence, Fraunces (opsz + wght), and Figtree from Google Fonts. Do not reintroduce Inter.

  3. Replace utility colors

    Swap existing stylesheet colors for tokens. Delete neon SaaS variables (#0b0c10 / cyan / violet / pink). Keep both cream and night-paper themes from this sheet.

  4. Rebuild components from recipes

    Buttons, cards, stamps, links, magazine tray, fields, focus — rebuild against this page rather than tinting old glass cards cream.

  5. Place characters with intent

    AtomicByte for identity; full cast for personality; AtomicMark for trademark. Never Lab Tech.

  6. Start from the pocket

    Mobile-first CSS, ~44px taps, no sideways page scroll. If the future site isn’t usable at 320, it isn’t using this system. See Responsiveness.
